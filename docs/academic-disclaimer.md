## Intended use

This project is intended **only for educational and evaluation purposes**. It is:

- not a production network,
- not a security assessment,
- not a recommendation for configuring real equipment.

The Packet Tracer designs put conceptual clarity ahead of production practice.

## Data and experimental context

The Wireshark captures were taken on the author's own home network, of the author's own traffic. On this site:

- the author's MAC address is shown redacted,
- no other person's traffic is published,
- the raw capture files are not published.

The Packet Tracer projects use simulated devices and addresses only.

## Academic integrity

All content, documentation and results on this site are part of a university coursework submission. They reflect original academic work unless otherwise cited, and comply with institutional academic integrity policies.
