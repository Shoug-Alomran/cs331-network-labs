First ping: 100% loss

  • PC A → PC2 failed: 4 timeouts.
  • Pinging PC A's own gateway (.1) failed too.
  • So the fault was local: cabling, addressing or the port. Routing wasn't the problem yet.

L1 · ROOT CAUSE

The cables were swapped

Switch1 (Network A, gateway .1) was plugged into G0/1 (.65). Switch2 was in G0/0. Each LAN's ARP for its gateway reached a port on the wrong subnet.

Fix: Switch1 → G0/0, Switch2 → G0/1.

What I learned

Subnet first

/26 gives 4 × 62 hosts. Block size 64 makes the boundaries easy to see.

Ping the gateway

If a host can't reach its own gateway, the problem is local. Look at Layer 1 first.

Port ↔ subnet

Up/up only means "cabled". It doesn't mean "cabled to the right subnet".

Read the TTL

TTL=127 from a 128 host means exactly one router hop.
